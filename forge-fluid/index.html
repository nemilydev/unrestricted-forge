step 0 · 0 alive · rule: gray-scott

Gray-Scott: reaction-diffusion. Two chemicals, one equation, patterns that look alive. F and k control the morphology — spots, stripes, mazes, chaos.

Conway: the classic. Live cell with 2-3 neighbors survives, dead cell with exactly 3 births. Complexity from a one-line rule.

Wireworld: a cellular clock. Electrons flow along wires. The simplest model of a circuit that still feels like one.

Click and drag on the canvas to draw. Each rule is a different answer to the same question: where does pattern come from when nobody's designing it?
